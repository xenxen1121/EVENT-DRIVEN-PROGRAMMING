# Lab 03 - React TypeScript

This laboratory activity demonstrates how to create a React application using Vite and TypeScript.

## Technologies Used

- React
- TypeScript
- Vite

## Components

The project contains two typed presentational components:

- `Panel.tsx`
- `Badge.tsx`

The components use TypeScript prop types and are composed together in `App.tsx`.

2. Open the terminal.
